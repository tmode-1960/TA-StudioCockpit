# Branding & Promo Assets Rule for tA-Studio-Cockpit

Whenever you create, refine, or export logos, app icons, Discord promo banners, or marketing graphics for **tA-Studio-Cockpit**:

1. Always save the final master files in the workspace under `assets/branding/` (for example `assets/branding/logo_tA.png` and `assets/branding/discord_promo_v<version>.png`), not only in the temporary conversation artifact directory.
2. Keep `assets/branding/` organized with clear, versioned or descriptive filenames so the user can always find and reuse them directly in the project directory.
